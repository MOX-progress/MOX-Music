# MOX Music

Übe-App für Gitarre und Bass: Metronom mit Drum-Grooves, Stimmgerät, Akkord- und Skalen-Finder mit Akkord-Suche, Tab-Editor, GP-Browser mit Player und Audio-Player mit A/B-Schleife.

Läuft im Browser und lässt sich auf dem iPhone über Safari → Teilen → „Zum Home-Bildschirm“ als App ablegen. Alle Daten (Tabs, Verlauf, Einstellungen) bleiben auf dem jeweiligen Gerät.
